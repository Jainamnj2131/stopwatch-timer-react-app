# ⏱ Stopwatch & Timer React App

A modern Stopwatch and Timer application built using React.js with responsive UI, lap tracking, countdown functionality, and clean state management.

---

## Features

### Stopwatch
- Start Stopwatch
- Pause Stopwatch
- Reset Stopwatch
- Lap Tracking System

### Timer
- Custom Time Input
- Countdown Timer
- Pause & Resume
- Reset Functionality
- Input Validation
- Alarm Sound on Completion

### UI Features
- Modern Glassmorphism Design
- Responsive Layout
- Interactive Buttons
- Clean User Experience

---

## Built With

- React.js
- JavaScript
- CSS3
- Vite
